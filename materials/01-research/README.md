# 01-research

Исследовательские материалы и заметки, на которых строится ВКР.

Основное:

- `analyze.md` — внешний deep research, который пользователь положил в репозиторий.
- `code-research.md` — технический анализ целевого проекта.
- `deep-research-prompt-external.md` — компактный промпт для внешнего исследования.
- `examples-analysis.md` — выводы по примерам ВКР.
- `questions.md` — вопросы и ответы, зафиксированные на старте.

Обычно эти файлы не являются финальным текстом ВКР, но из них можно брать аргументы, формулировки и ограничения.
