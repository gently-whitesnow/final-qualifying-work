# 00-source-documents

Исходные документы, полученные извне: методички, шаблоны, примеры и архивы.

Эти файлы считаются входными данными. Их не нужно редактировать, кроме случаев, когда пользователь явно просит заполнить конкретный шаблон.

Основное:

- `Практика2026заочное.pdf` — требования по практике.
- `Программная_инженерия._Требования_к_подготовке_и_содержанию_отчетов_по_практике.pdf` — пособие по оформлению отчетов.
- `ИндивидуальноеЗадание2026заоч.docx` — шаблон индивидуального задания.
- `ТитульныйЛист2026заочное.docx` — шаблон титульного листа.
- `ШаблонПДП2026.pptx` — шаблон презентации.
- `examples_extracted/` — распакованные примеры ВКР.
