# Материалы

Папка разделена по назначению, чтобы следующий агент или человек быстро понимал, где искать входные данные, план и текущий текст.

## Разделы

- `00-source-documents/` — методички, шаблоны, примеры ВКР, архив `examples.zip`.
- `01-research/` — результаты анализа, вопросы, deep-research промпты, заметки по целевому проекту.
- `02-planning/` — планы и спецификации: что реализовывать, чем доказывать, как защищать вклад.
- `03-proof-stand/` — запуск стенда, smoke-тесты, результаты экспериментов.
- `04-docx/` — контент ВКР и инструкция по сборке DOCX.
- `99-handoff/` — краткий контекст для продолжения работы агентом.

## Что считать главным

- Текущий текст ВКР: `04-docx/vkr-draft-content.md`
- Pipeline DOCX: `04-docx/docx-pipeline.md`
- Текущий технический handoff: `99-handoff/agent-handoff.md`
- Лог эксперимента: `03-proof-stand/experiment-log-2026-05-09.md`
- Runbook стенда: `03-proof-stand/runbook-thesis-stand.md`
