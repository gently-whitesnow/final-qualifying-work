# 04-docx

Материалы для сборки DOCX.

Основное:

- `vkr-draft-content.md` — главный источник текста ВКР.
- `docx-pipeline.md` — правила сборки, render-QA и текущий статус DOCX.

Правило: текст править здесь, оформление — в `../../scripts/build_vkr_docx.py`, затем пересобирать `../../build/docx/vkr-draft-1.docx`.
