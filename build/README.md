# Build

Здесь лежат воспроизводимые результаты сборки. Эти файлы можно пересоздать из `materials/04-docx/vkr-draft-content.md` и `scripts/build_vkr_docx.py`.

## Важные файлы

- `docx/vkr-draft-1.docx` — актуальный черновик ВКР в DOCX.
- `docx/assets/` — сгенерированные иллюстрации, вставляемые в DOCX.
- `docx/rendered/` — PDF и PNG-страницы для визуальной проверки.

Если нужно изменить документ, править нужно исходный Markdown или генератор, затем пересобрать DOCX и render-QA.
