# Scripts

В этой папке лежат воспроизводимые скрипты проекта.

## `build_vkr_docx.py`

Собирает DOCX из `materials/04-docx/vkr-draft-content.md`, добавляет титульные страницы, содержание, сокращения, основной текст, источники, приложения и сгенерированные иллюстрации.

Запуск:

```bash
cd /Users/gently/projects/final-qualifying-work
/Users/gently/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 scripts/build_vkr_docx.py
```
